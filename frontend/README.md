# RiskBridge AI

AI-powered payment risk intelligence and management platform.

RiskBridge AI helps merchants monitor payment risk, understand the factors driving risk, simulate potential changes in merchant activity, and take informed remediation actions. It combines real-time payment signals, risk assessment, AI-powered investigation, scenario simulation, and auditable risk workflows in one platform.

Built for modern payment businesses that want to move beyond basic risk detection toward explainable, proactive, and actionable risk management.
## 🎯 Problem Statement

As digital payments grow, merchants generate large volumes of transaction data that can contain important signals of emerging payment risk. However, **identifying a risk signal is only the first step.**

Merchants need a way to continuously **monitor payment activity**, understand **why risk is increasing**, evaluate **how changing business conditions could affect future risk**, and determine **what actions can have the greatest impact**.

Traditional risk monitoring often focuses on detecting anomalies or assigning a risk score, but does not provide a complete workflow from:

### 🔎 Detection → 🧠 Explanation → 🧪 Simulation → 🛠️ Remediation → 👤 Review → 📋 Audit


RiskBridge AI addresses this gap by building an **AI-powered risk management layer** that turns payment signals into **explainable, actionable risk intelligence**.

## 🚀 Solution

### 🛡️ Turning Payment Risk into Actionable Intelligence

RiskBridge AI is an AI-powered payment risk management platform that helps merchants **detect, understand, predict, and respond to risk**.

Rather than simply generating a risk score, RiskBridge AI explains **why the risk exists**, evaluates **how risk could change**, and helps determine **what action can reduce it**.

### 🔄 End-to-End Risk Workflow



**🔎 Detect → 🧠 Investigate → 🧪 Simulate → 🛠️ Remediate → 👤 Review → 📋 Audit**



| Stage | What RiskBridge AI Does |
|---|---|
| 🔎 **Detect** | Monitors payment activity and identifies signals such as refund rate, dispute rate, device/IP anomalies, and behavioral changes. |
| 🧠 **Investigate** | Uses AI to analyze risk signals and explain the key factors contributing to the risk score. |
| 🧪 **Simulate** | Evaluates how changes in merchant conditions could affect future payment risk. |
| 🛠️ **Remediate** | Identifies high-impact interventions based on projected risk outcomes. |
| 👤 **Review** | Provides a structured workflow for teams to review risk cases and decisions. |
| 📋 **Audit** | Records risk decisions and actions for traceability and accountability. |

### 💡 What Makes RiskBridge AI Different

Traditional risk systems often follow:

**Payment Data → Risk Score → Alert**

RiskBridge AI extends this into an actionable intelligence loop:

**Payment Data → Risk Signals → Risk Assessment → AI Investigation → Simulation → Remediation → Review → Audit**

This creates a complete path from **detecting a risk to understanding it and deciding what to do next**.

## 🔄 How It Works

RiskBridge AI follows an end-to-end pipeline that transforms payment activity into explainable and actionable risk intelligence.

### 1️⃣ Payment & Merchant Data

The system collects merchant profiles, payment activity, transaction history, and relevant behavioral information.

⬇️

### 2️⃣ Transaction Signals

The Risk Engine evaluates payment activity and identifies important risk signals such as:

- Refund rate
- Dispute rate
- Device/IP anomalies
- Behavioral changes
- Payment-level risk indicators

⬇️

### 3️⃣ Risk Assessment

The identified signals are processed by the Risk Engine to generate a **risk score, risk level, and contributing factors**.

⬇️

### 4️⃣ Real-Time Risk Pipeline

**Redis + Apache Kafka** support event-driven processing and help move transaction and risk signals through the system efficiently.

⬇️

### 5️⃣ AI Investigation

The **AI Context Engine** combines merchant, payment, transaction, and risk information into investigation context.

The **AI Risk Investigation Agent** then:

- Identifies the main risk drivers
- Explains why the risk exists
- Analyzes relevant signals
- Generates actionable recommendations

⬇️

### 6️⃣ Risk Simulation

The Risk Simulator allows users to change merchant conditions and evaluate how those changes could affect projected risk.

⬇️

### 7️⃣ Remediation

The **Remediation Agent** evaluates projected outcomes and identifies high-impact actions that can help reduce risk.

⬇️

### 8️⃣ Human Review & Audit

Risk cases can be reviewed through the **Review Center**, while important decisions and actions are recorded in the **Audit Log**.

# 🚀 Run Locally

Get **RiskBridge AI** running locally in a few simple steps.

## 🧰 Prerequisites

Make sure you have the following installed:

- 🐍 **Python 3.10+**
- 🟢 **Node.js 18+**
- 📦 **npm**
- 🐘 **PostgreSQL**
- 🔴 **Redis**
- 📨 **Apache Kafka**
- 🐳 **Docker** *(recommended for local infrastructure)*

## 1️⃣ 📥 Clone the Repository

Clone the RiskBridge AI repository and move into the project directory.

    git clone https://github.com/maalideekshith/RiskBridge-AI.git
    cd RiskBridge-AI

## 2️⃣ 🗄️ Database & Infrastructure Setup

RiskBridge AI uses **PostgreSQL** for persistent application data and **Redis + Apache Kafka** for real-time risk processing.

Make sure PostgreSQL is running and create a database for the project.

Example:

    riskbridge

Redis and Kafka can be started using the provided Docker Compose configuration:

    docker compose up -d

Verify that the required infrastructure services are running before starting the backend.

## 3️⃣ ⚙️ Backend Setup

Navigate to the backend directory:

    cd backend

Create a Python virtual environment:

    python -m venv venv

Activate the virtual environment.

### Windows

    venv\Scripts\activate

### macOS/Linux

    source venv/bin/activate

Install the backend dependencies:

    pip install -r requirements.txt

Create a `.env` file inside the `backend` directory and configure your local environment.

Example:

    DATABASE_URL=your_postgresql_connection_string
    JWT_SECRET=your_secure_jwt_secret
    JWT_ALGORITHM=HS256
    JWT_ACCESS_TOKEN_EXPIRE_MINUTES=30

    REDIS_URL=redis://localhost:6379

    KAFKA_BOOTSTRAP_SERVERS=localhost:9092

    OPENROUTER_API_KEY=your_openrouter_api_key

> 🔐 Keep API keys, database credentials, and JWT secrets private. Never commit `.env` files to GitHub.

Start the FastAPI backend:

    uvicorn app.main:app --reload

The backend will be available at:

- ⚙️ **API:** http://localhost:8000
- 📚 **Swagger Documentation:** http://localhost:8000/docs
- 📖 **OpenAPI Schema:** http://localhost:8000/openapi.json

## 4️⃣ 🎨 Frontend Setup

Open a new terminal and navigate to the frontend directory:

    cd RiskBridge-AI/frontend

Install the frontend dependencies:

    npm install

Create a `.env` file inside the `frontend` directory:

    VITE_API_BASE_URL=http://127.0.0.1:8000

Start the Vite development server:

    npm run dev

The frontend will be available at:

- 💻 **Application:** http://localhost:5173

## 5️⃣ 🤖 AI Configuration

RiskBridge AI uses **OpenRouter** to connect the AI investigation workflow with an LLM.

Add your OpenRouter API key to the backend `.env` file:

    OPENROUTER_API_KEY=your_openrouter_api_key

The AI layer powers:

- 🧠 AI Risk Investigation
- 💡 Risk explanations
- 🎯 Risk recommendations
- 🤖 Remediation intelligence

> ⚠️ Never expose the OpenRouter API key in the frontend or commit it to source control.

## 6️⃣ 🔄 Start the Complete System

Run the required services in separate terminals.

### Terminal 1 — Infrastructure

From the project root:

    docker compose up -d

### Terminal 2 — Backend

    cd backend
    venv\Scripts\activate
    uvicorn app.main:app --reload

### Terminal 3 — Frontend

    cd frontend
    npm run dev

Then open:

    http://localhost:5173
